# agent-files

Published skills live in `skills/`. To add one, run `/add-new-skill` ([.claude/skills/add-new-skill/SKILL.md](.claude/skills/add-new-skill/SKILL.md)). Shape: [.claude/skill-folder.md](.claude/skill-folder.md). Heroes: [.claude/data/generate-hero.md](.claude/data/generate-hero.md). Root world map: [.claude/data/skill-map.yaml](.claude/data/skill-map.yaml) is the roster, `/generate-world-map` ([.claude/skills/generate-world-map/SKILL.md](.claude/skills/generate-world-map/SKILL.md)) repaints it. Image prompts stay in the session, never on a PR.

Published Grok Bot packages live in `grok-bot/`. To add one, run `/add-new-grok-bot-skill` ([.claude/skills/add-new-grok-bot-skill/SKILL.md](.claude/skills/add-new-grok-bot-skill/SKILL.md)). Shape: [.claude/grok-bot-folder.md](.claude/grok-bot-folder.md). Heroes: `/generate-grok-bot-hero-prompt` ([.claude/skills/generate-grok-bot-hero-prompt/SKILL.md](.claude/skills/generate-grok-bot-hero-prompt/SKILL.md)) then GenerateImage in Grok Bot (orbs on old-west waterworks; 16:9 is fine). Do not add grok-bot packages to `skill-map.yaml`.
