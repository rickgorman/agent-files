# agent-files

Published skills live in `skills/`. To add one, run `/add-new-skill` ([.claude/skills/add-new-skill/SKILL.md](.claude/skills/add-new-skill/SKILL.md)). Shape: [.claude/skill-folder.md](.claude/skill-folder.md). Heroes: [.claude/data/generate-hero.md](.claude/data/generate-hero.md). Root world map: [.claude/data/skill-map.yaml](.claude/data/skill-map.yaml) is the roster, [.claude/data/generate-world-map.md](.claude/data/generate-world-map.md) repaints it. Image prompts stay in the session, never on a PR.
